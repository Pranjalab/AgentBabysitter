Run these from the repo root (`~/Projects/research/AgentBabysitter`) on branch
`v3-daemon`. Each step lists the exact command and what you should see. Nothing here
touches your real profiles, bots, or `~/.abs`.

```bash
.venv/bin/python -m pytest
```

## 4. `abs help` still shows all v2 commands, plus the new daemon line

```bash

```

Expect: the full v2 help you know (setup, status, profiles, usage, menu, voice, say,
log, quiet, off, on, exit, config …, update, reset, version, help) renders unchanged,


## 5. A normal help-level invocation isn't broken

```bash
bash abs.sh version; echo "exit=$?"
bash abs.sh --help >/dev/null; echo "help exit=$?"
```

Expect: `Agent Babysitter 2.6.0` / `exit=0`, and `help exit=0`.

> Do NOT run bare `bash abs.sh` here — with no subcommand it would try to launch a
> real session. `help`/`version`/`daemon` are the safe no-session invocations.
