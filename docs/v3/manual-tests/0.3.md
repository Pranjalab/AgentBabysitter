## 2. (optional) Watch fake-claude behave by hand

```bash
# normal: stays alive, writes a PID, cleans up on Ctrl-C
tests/harness/fake-claude --mode normal --pid-file /tmp/fc.pid &
cat /tmp/fc.pid          # a live PID

# not-logged-in: exits 1 fast with an auth-style stderr line

# crash-after: exits non-zero after ~1s
tests/harness/fake-claude --mode crash-after-1; echo "exit=$?"
```
