# Manual test — Step 1.5: ABS START (the headline demo)

Phone-only remote session start, with the terminal used once to register a
project. Your setup: one profile **`default`**, daemon already installed +
enabled. **The flow only works while NO session is live for the profile** — if a
session is running, `ABS START` just replies with the attach hint. So start from
a clean state: no `abs` session running.

> ⚠️ **One-time prep for the unit fix.** Step 1.5 fixes `absd.service` (the
> `StartLimitIntervalSec`/`StartLimitBurst` keys moved to `[Unit]`; systemd was
> logging "Unknown key, ignoring"). It does **not** take effect until you
> reinstall the unit:
>
> ```
> abs daemon install
> systemctl --user daemon-reload
> systemctl --user restart absd
> systemctl --user status absd     # no more "Unknown key" warnings in the log
> ```

---

## Phase A — register a project (terminal, once)

Registration and the workspace root are **terminal-only** by design (a phone can
never name a filesystem path).

1. Pick a real project directory and register it:

   ```
   abs project add ~/Projects/somerepo
   abs project list
   ```

   Expected: `list` prints one line, `somerepo` with its absolute path.

2. (Optional, for the "New folder" step later) set a workspace root:

   ```
   abs config workspace-root ~/Projects
   abs config workspace-root --show      # prints the resolved path
   ```

   New folders started from the phone can **only** be created directly under this
   root — nowhere else.

3. Make sure no session is live for `default`:

   ```
   abs sessions          # should list nothing alive for 'default'
   abs daemon status     # 'default: polling …' (not yielding-to-session)
   ```

## Phase B — start a session from the phone

From your Telegram chat with the bot:

4. Send exactly: **`ABS START`**

   Expected reply: a message **"📂 Which project?…"** with inline buttons — one per
   registered project + workspace-root child, then **"➕ New folder"** — and the
   same list numbered (you can tap a button *or* reply with the number).

5. Tap your project's button (or reply its number).

   Expected: **"🔐 Permission mode?"** with **🟢 Normal** and **🟡 Away** buttons
   (or reply `1` / `2`). Normal asks before file edits; Away auto-accepts them.

6. Tap **🟢 Normal**.

   Expected within a couple of seconds: a confirmation like **"🚀 Started
   `somerepo` (normal). Send it a task here, or attach at the terminal:"** followed
   by **two** commands — `abs attach default` and the exact engine command (e.g.
   `herdr session attach abs-default` or `tmux -L abs attach -t abs-default`). Use
   either; both reach the same session. The daemon has launched Claude Code in that
   project inside the session engine.

7. Send the session a real task as a normal Telegram message, e.g.
   *"list the files in this repo and tell me what it does."*

   Expected: a normal Claude Code reply — you are now talking to a live session the
   **daemon started for you**, not the idle daemon.

## Phase C — attach at the desk, then end from the phone

8. At the terminal, use **either** command from the confirmation message
   (they now resolve to whichever engine actually launched the session — `abs
   attach` searches both tmux and herdr, so it is no longer engine-blind):

   ```
   abs attach default        # or the exact engine command that was printed
   abs sessions              # lists live sessions across BOTH engines (ENGINE column)
   ```

   Expected: `abs sessions` shows your session with its engine; `abs attach` drops
   you straight into it (scrollback, mouse scroll with the tuned conf). Detach
   without killing it: **tmux** `Ctrl-b d` / **herdr** `Ctrl-b q`. The session keeps
   running.

9. From the phone, end it: send **`ABS EXIT`** (confirm if it asks).

   Expected: after the session closes, within ~5–10s you get **"⏹ Session ended.
   I'm listening again — send ABS START to begin."** — the daemon has reclaimed the
   bot and is polling again. Send a plain message now and you should get the pool
   ack (daemon, not a session).

## Phase D — the "New folder" path (D6 jail)

10. `ABS START` again → at the project menu tap **➕ New folder**.

    Expected: **"📝 Name the new folder…"**.

11. Try a bad name first, e.g. `../evil` or `/etc` or `my project` (with a space).

    Expected: **"❌ …"** with the rules, and a re-prompt. Nothing is created.

12. Send a valid name, e.g. `scratch-demo`.

    Expected: the mode prompt. Pick Normal. The session starts in
    `~/Projects/scratch-demo` (verify at the terminal it was created **only** there:
    `ls ~/Projects/scratch-demo`). End it with `ABS EXIT`.

## Phase E — edge behaviours (quick checks)

- **Start while live:** with a session running, send `ABS START` → you get the
  attach hint, **no** new flow. (End the session first to start a new one.)
- **Timeout:** send `ABS START`, then wait 5+ minutes without answering → send
  anything → you get **"⌛ ABS START timed out…"**; a fresh `ABS START` restarts it.
- **Away mode:** run the flow picking **🟡 Away**; the confirmation says `(away)`,
  and inside the session file edits no longer prompt (Bash still guards).

## What this does NOT cover (later steps)

- **Login detection** (Step 1.6): starting against an unpaired/not-logged-in
  profile currently fails generically (the launcher dies "not paired", or a
  never-alive session is reclaimed) rather than a "please log in" message.
- **Pool forwarding** (Step 1.7): messages pooled while idle are kept but not yet
  offered for forwarding into a freshly started session.
- **Three bots at once** (G5): the machinery is per-profile and independent, but
  with one bot you can only verify one at a time. Repeat A–C on a second
  profile/bot when you have one.

## Safety note (read once)

`ABS START` can launch a real, fully-capable Claude Code session in any project
you **registered** or any directory under your **workspace root** — a stolen phone
can too. Register only projects you accept remote starts into, keep the workspace
root scoped, and remember the terminal-only recovery: `abs off` / `ABS BLOCK`
(re-enabled only at the desk) stop the bot cold.
